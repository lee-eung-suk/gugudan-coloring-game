# 🎨 곱셈구구 색칠하기

초등 2학년이 만든 원작을 닌텐도 게임풍으로 새로 디자인한 곱셈구구 색칠 놀이입니다.

## 놀이 방법

1. **몇 단을 할까요?** 화면에서 2단~9단 카드 중 하나를 고르거나 **랜덤 도전**을 선택합니다.
2. 그림 속 곱셈 문제(예: `2 × 4`)를 계산합니다.
3. 아래 팔레트에서 정답 숫자 물감을 누른 뒤, 그림에서 같은 문제가 적힌 부위를 눌러 색칠합니다.
4. 모든 부위를 색칠하면 그 동물이 완성되고, 실수 없이 완성하면 별 3개를 받습니다.
5. **내 도감**에서 지금까지 모은 동물을 확인할 수 있습니다.

## 구성

- 구구단 2단~9단 = 8종 동물 (토끼·곰·고양이·펭귄·사자·호랑이·개구리·여우) + 랜덤 도전
- 완성된 그림이 실제 그 동물처럼 보이도록 부위별 색을 미리 디자인
- 매 플레이마다 문제 배치가 랜덤으로 섞임
- 힌트·오답 횟수에 따른 별점(★~★★★), `localStorage` 진행 저장
- 사운드는 Web Audio API로 직접 생성 (외부 음원 파일 없음)

## 파일 구조

```
gugudan-coloring-game/
├── index.html         화면(타이틀/셀렉트/플레이/도감) 마크업
├── css/style.css       닌텐도풍 스타일
├── js/
│   ├── animals.js      동물 8종의 색칠 영역 데이터
│   ├── sound.js         효과음
│   └── app.js            게임 로직 (화면 전환, 출제, 채점, 저장)
└── original.html       학생이 만든 원본 버전 (보관용)
```

## 로컬 실행

별도 빌드 없이 정적 파일이므로 `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.

```bash
npx serve .
```
